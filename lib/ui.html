browserpit

v%VERSION%

Separate, visible browsers. Each ID has its own cookies, logins and storage – nothing is shared between them. Give Claude any of them with one command.

    How Claude gets access

    Each instance is its own MCP server. The command under an instance adds it to Claude Code; Claude then drives exactly that browser window while you watch. Several instances = several servers (e.g. read with one account, post with another).

    Claude Desktop or other MCP clients: command npx, arguments -y browserpit mcp <id>. Logins, 2FA and captchas you do yourself in the window.
